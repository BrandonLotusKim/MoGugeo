# 개인정보 처리방침 (모국어 / MoGugeo)

최종 갱신: 2026-05-14

본 문서는 "모국어(MoGugeo)" 데스크톱 애플리케이션 ("본 앱") 의 개인정보 처리방침입니다.

## 1. 수집하는 개인정보

본 앱은 회원가입이 필수입니다 (게스트 모드 없음). 수집 항목:

### 필수 항목
- 아이디 (로그인 ID)
- 비밀번호 (해시 처리되어 저장, 평문 보관 안 함)
- 닉네임 (화면 표시명)

### 선택 항목 (입력한 경우에만 수집)
- 이메일 — 비밀번호 분실 시 복구 용도
- 전화번호 — 향후 본인확인 기능 대비 저장 (현재 미사용)
- 통신사 — 향후 본인확인 기능 대비 저장 (현재 미사용)

### 자동 생성·기록되는 정보
- 로그인 기록 (접속 시각, IP, 디바이스 정보, 성공 여부)
- 학습 활동 데이터 (학습 기록, 점수, 정답 여부, 스트릭, 복습 큐, 학습 설정)

## 2. 개인정보 이용 목적

- 회원 식별 및 로그인 인증
- 학습 진도·통계 제공 및 동기화
- 비밀번호 분실 시 본인 확인 및 재설정 (이메일 등록자에 한함)
- 콘텐츠 자동 갱신 및 앱 자동 업데이트
- 부정 접속 확인 (로그인 기록)

전화번호·통신사는 **현재 어떤 기능에도 사용하지 않으며**, 향후 본인확인 기능 도입 시 활용을 위해 저장만 합니다. 도입 시 본 방침을 개정하고 별도 고지합니다.

## 3. 보유 및 이용 기간

- 회원 정보·학습 데이터: 회원 탈퇴 시까지
- 로그인 기록: 수집일로부터 일정 기간 후 자동 삭제
- 회원 탈퇴 시 모든 개인정보와 학습 데이터를 지체 없이 삭제합니다.

## 4. 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다.

## 5. 처리 위탁

- 데이터 저장 및 인증: Supabase (PostgreSQL 호스팅, 인증 서비스)
- 앱 배포·콘텐츠 호스팅: GitHub

## 6. 사용자 권리

- 환경설정·개인정보 편집 화면에서 닉네임, 이메일, 전화번호, 통신사, 비밀번호를 변경할 수 있습니다.
- 회원 탈퇴를 요청하면 모든 개인정보와 학습 데이터가 삭제됩니다.
- 비밀번호 분실 시: 이메일을 등록한 사용자는 등록 이메일로 재설정할 수 있습니다. 이메일 미등록 사용자는 관리자 문의를 통해 처리합니다.

## 7. 보안 조치

- 비밀번호는 해시 처리되어 저장되며 평문으로 보관하지 않습니다.
- 서버 통신은 HTTPS 로 암호화됩니다.
- 인증 토큰은 운영체제의 보안 저장소(Electron safeStorage)에 보관됩니다.
- 자동 업데이트 패키지의 무결성 검증은 v1.x 후반 코드 사이닝 도입 시 적용됩니다.

## 8. 개인정보 보호책임자

- 본 앱의 운영자가 개인정보 보호책임자를 겸합니다.
- 문의: 앱 내 "문제 신고" 메뉴 또는 GitHub Issues

## 9. 방침 변경

본 방침이 변경되는 경우 앱 내 알림 또는 changelog 를 통해 고지합니다.
