⚠️ 컨셉 변경 안내
초안(2026-04 작성)은 "공용 게시판" 형태였으나,
실제 빌드는 학습 앱 컨셉으로 진행되어 이 문서를 개정한다.
기존 게시판 컨셉은 폐기.

상세 정의는 다음 문서를 정본으로 참조:
- Document/FeatureSpec.md   : 5개 기능 상세 정의
- Document/Architecture-v2.md : DB·인프라 아키텍처
- Document/Roadmap.md       : 통합 체크리스트

1. 서비스 목표
- 매일 아침 데스크톱에서 영어 학습 루틴을 5~10분 안에 수행한다.
- 정해진 시각에 데일리 팝업이 자동으로 떠 짧은 학습 미션을 제시한다.
- 문장 해석을 중심으로 학습하고, 스트릭으로 학습 동기를 유지한다.

2. MVP 범위 — 활성 기능 5개
[포함]
- 회원가입 (아이디 기반, 게스트 모드 없음)
- 로그인 (자동 로그인, 비밀번호 찾기)
- 데일리 팝업 (정시 트리거, 영↔한 양방향 2문제)
- 문장 해석 (영어→한국어 번역, 채점, 피드백)
- 학업 성취도 (스트릭, 정답률, 학습 빈도, 복습 큐)
- 콘텐츠: 문장 50개 (초기 빌드 동봉)
- 복습 큐 (틀린 문장 망각곡선 재출제)
- 다크모드
- TTS 발음 재생 (문장 해석 화면)

[비활성 — 보존만]
- 단어 학습, 원어민 표현 → src/renderer/_disabled/ 로 백업
- 레벨 시스템 → 제거 (동기 부여는 스트릭이 담당)

[제외 — v2 이후 또는 미정]
- 소셜 로그인 (네이버·카카오 연동)
- 전화번호 SMS 인증, 통신사 본인확인 (무과금 제약 — 데이터 저장만)
- 사용자 간 소셜 기능
- 모바일 앱

3. 회원가입·계정 정책
- 회원가입 필수 (게스트 모드 없음)
- 아이디 + 비밀번호 + 닉네임 (필수)
- 이메일·전화번호·통신사 (선택 입력) — 이메일은 비번 복구용
- 인증: Supabase Auth + 아이디→내부 이메일 매핑 방식

4. 난이도 정책
- 사용자 고정 — 회원가입 후 최초 로그인 시 1회 선택
- 이후 환경설정/개인정보 편집에서 변경 가능
- 풀이 화면에 난이도·카테고리 라벨 노출 금지

5. 초기 성공 기준
- 회원가입 후 즉시 학습 시작 가능
- 다음 날 같은 시각에 데일리 팝업이 자동으로 뜬다 (앱 실행 여부 무관)
- 7일 연속 학습 시 7일 스트릭 정상 표시
- 인터넷 끊겨도 학습 가능 (콘텐츠 캐시)
- 인프라 비용 0원 (무료 티어만 사용)

6. 인프라 (무과금 확정)
- DB·인증·API: Supabase 무료 티어
- 콘텐츠·인스톨러 호스팅: GitHub Releases + Pages
- 유료 전환 계획 없음

7. 이행 경로
- STAGE C  : 클라이언트 기능 완성 (localStorage 기반)
- STAGE P1~P4 : Supabase 기반 v2 (콘텐츠 백엔드 → 인증 → 동기화 → 운영)
- STAGE Q/R : 품질·보안 / 배포
- 상세는 Document/Roadmap.md
