📌 프로젝트 계획서 (MVP 기준)
============================================================

1. 프로젝트 목표
------------------------------------------------------------
- 사용자가 웹사이트에서 Windows 설치 파일 다운로드
- Electron 앱 설치 후 실행 시
  -> 로컬 HTML이 아닌 서버 웹페이지 표시

- 웹 페이지 역할
  -> 공용 게시판 서비스
  -> 관리자 글 등록 시 모든 사용자에게 실시간 반영


2. 권장 아키텍처
------------------------------------------------------------
[클라우드]
- DigitalOcean

[서비스 구성]
- 웹 호스팅       : App Platform
- 데이터베이스    : Managed PostgreSQL
- 파일 저장소     : Spaces (설치파일 및 정적 파일)
- 도메인          : 사용자 전용 도메인 1개

[클라이언트]
- Electron 앱
  -> loadURL로 서버 웹페이지 호출

[웹 기술]
- Next.js + TypeScript
- PostgreSQL


3. 구성 선택 이유
------------------------------------------------------------
✔ DigitalOcean
  - AWS / Azure 대비 단순한 초기 세팅

✔ App Platform
  - 서버 운영 부담 최소화

✔ PostgreSQL
  - 게시판 / 계정 / 권한 / 확장성 대응 가능

✔ Spaces
  - 설치 파일 및 정적 파일 관리에 적합


4. 예상 비용 (월 기준)
------------------------------------------------------------
- App Platform      : 약 $5~ (약 6,700원~)
- PostgreSQL        : 약 $15.15~ (약 20,300원~)
- Spaces            : 약 $5~ (약 6,700원~)

-> 총 예상 비용
   : 약 $25 ~ $30 (약 33,500원 ~ 40,200원, 도메인 제외)
